# 第 8 课：因子预处理

> 对照：`Parsnip77/src/preprocessor.py` 的 `FactorCleaner`  
> 我们的代码：`factor_lite/my_preprocess.py`

## 仓库 FactorCleaner 怎么做？

1. **去极值**：MAD 法（中位数绝对偏差），不是百分位。  
   边界 = `中位数 ± 3 × 1.4826 × MAD`。  
   **截面**（同一天、所有股票一起），不是沿时间。  
   `1.4826` 把 MAD 换算成和标准差差不多的尺度（正态分布下）。

2. **标准化**：截面 **z-score**（减当天均值，除以当天标准差），不是 rank。  
   仓库在中性化前后各做一次；我们精简版只做一次（去极值之后、中性化之前）。

3. **中性化**：截面 **OLS**（普通最小二乘回归），取残差。  
   仓库的自变量是：`log(total_mv)` + 行业哑变量。  
   我们精简版按你的要求：只用 **industry 哑变量**（不加市值）。

**截面**：同一个交易日，把池子里股票摆在一起处理。  
**哑变量**：把「银行 / 房地产 / …」变成 0/1 列，方便塞进回归。  
**残差**：真实因子值 − 回归拟合值，留下「行业解释不了的部分」。

## 我们脚本的流水线

`factors_raw` → 去极值 → z-score → 行业中性化 → `factors_clean`

行业来自 `meta` 里的 `industry`（Tushare `stock_basic`，非申万、非历史时点）。

## 怎么验证

- 去极值：同一天、同一因子，清洗后 max 应 ≤ 边界，极端值被夹住。  
- 标准化：按日看均值应接近 0，标准差接近 1。  
- 中性化：按日、按行业看均值，行业之间差异应比中性化前更小。
