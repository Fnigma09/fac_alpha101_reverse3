# 第 1 课：配置在哪？哪些其实不在 config？

> 对照：`Parsnip77/src/config_template.py`（要自己改成 `config.py`）  
> 以及：`analyze_main.py`、`backtester.py`

## 先记住一件事

名字叫「全局配置」的文件，**并没有装下所有旋钮**。  
有的在 config，有的写死在别的脚本里。复写时建议你自己集中放一处，少踩坑。

## config 里有的

| 名字 | 白话 | 默认值 |
|------|------|--------|
| `TUSHARE_TOKEN` | 数据网站账号钥匙 | 需你自己填 |
| `START_DATE` / `END_DATE` | 下载从哪天到哪天 | `20190101` ~ `20231231` |
| `UNIVERSE_INDEX` | 股票池用哪个指数 | `000300.SH`（沪深300） |
| `DB_PATH` | 本地数据库相对路径 | `../data/stock_data.db` |
| `SLEEP_PER_CALL` | 两次下载之间歇多久，避免被限流 | `0.35` 秒 |

日期写法是八位数字字符串，例如 `"20190101"`，不是带横线的日期。

## config 里没有、但很重要的

| 你以为在 config | 实际在哪 | 值 |
|-----------------|----------|-----|
| 用哪些因子 | `alphas.py` 里叫 `alpha...` 的函数 | 大约 16 个；**没有 Alpha#23** |
| 分成几组回测 | `LayeredBacktester`，默认参数 | **5 组** |
| 拿多久收益当答案 | `analyze_main.py` 的 `FORWARD_DAYS` | **1**（下一交易日） |
| 手续费 | — | **阶段 2 没做** |
| IC 多好才留因子 | `analyze_main.py` | \|均值\| > 0.02，且 \|ICIR\| > 0.30 |

**ICIR**：IC 的平均值 ÷ IC 的波动。大致表示「相关程度稳不稳」；越大越稳（方向要对，看绝对值筛选时两边都算）。

## 复写时建议

精简版可以只在一个 `config.py` 里写清：

- 数据路径、起止日期、股票池  
- 要用的因子名单  
- 分组数、持有几天、（以后若需要）手续费
