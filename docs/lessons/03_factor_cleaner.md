# 第 3 课：因子算完后为什么还要「洗」？

> 对照：`Parsnip77/src/preprocessor.py`（类名 `FactorCleaner`）

## 为什么要洗？

原始因子可能：

- 出现极大/极小的离谱数（某只股票某一天炸了）；  
- 不同股票的分数尺度差很多；  
- 分数其实只是在反映「大公司」或「某个行业」，不是你想要的规律。

清洗就是：压极端值 → 拉到同一尺度 → 尽量去掉市值、行业带来的偏斜 → 再对齐一次尺度。

## 「截面」是什么意思？

**截面**：在**同一个交易日**，把池子里所有股票摆在一起比较/处理。  
不是「一只股票顺着时间算」。

这个清洗管线的每一步，默认都是**按天、在截面上**做的。

## 六步（按仓库真实顺序）

1. **把无穷大当成缺失**  
   算崩了会出现 ±∞，先改成空值，后面好处理。

2. **去极端值（MAD 法）**  
   - 先找这一天分数的**中位数**（中间那个数，比平均数抗极端值）。  
   - 再看大家离中位数有多远（MAD）。  
   - 超出「中位数 ± 3 × 1.4826 × MAD」的，夹到边界上。  
   白话：特别飞的分数往回收一收，别带着整体乱跑。

3. **第一次标准化（Z 分数）**  
   当天：减去平均，再除以波动。  
   白话：把当天分数拉成「大约均值 0、波动 1」的刻度，方便股票之间比。

4. **中性化（对市值、行业做回归，留残差）**  
   白话：用统计方法估计「有多少分只是因为公司大、或属于某行业」，把这部分减掉，留下「说不清的那部分」当新分数。  
   （仓库用的是：对 `log(总市值)` 和行业哑变量做最小二乘，取残差。）

5. **再标准化一次**  
   中性化后尺度又乱了，再做一遍 Z 分数。

6. **空值填 0，然后主脚本把不可交易的格子改回空**  
   清洗类内部先把空填成 0；`data_preparation_main` 再把买不了的股票那天改回空，避免回测把它们当中性票硬分进去。

## 输入 / 输出

- 输入：原始因子表（行是「某日某股」）+ 市值、行业。  
- 输出：同形状的清洗后因子；不可交易位置最终应是空值。
