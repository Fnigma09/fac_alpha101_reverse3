# 先只看这一页（其他都可以先不看）

你现在只要记住 **3 件事**。

## 1. 我们在干嘛？

把股票每天的价格整理成两张表，供以后算「打分规则」用。

就这样。还没有因子、没有回测、没有机器学习。

想看三个脚本谁调用谁：打开 `factor_lite/docs/CODE_MAP.md`（调用树：从上往下是谁调用谁）。

## 2. 你已经有什么？

| 东西 | 一句话 |
|------|--------|
| 本地原始数据 | `tushare_data/...` 里下载好的行情 |
| 整理脚本 | `factor_lite/my_data_prep.py` |
| 整理结果 | `factor_lite/data/prices.parquet` 和 `meta.parquet` |

**prices** = 每天每只股票的价格（开高低收、成交量等）  
**meta** = 每天每只股票的补充信息（行业、市值等）

两张表的**主键**（也叫关联键）是 `trade_date` + `ts_code`。  
主键就是能唯一标出「哪一天、哪只股票」的那几列；两张表靠它合并。
