# 第 2 课：数据从哪来？两张表长什么样？

> 对照：`Parsnip77/src/data_loader.py`（类名 `DataEngine`）  
> 导出表结构还看：`data_preparation_main.py`

## 它在干什么（白话）

1. **下载一次**，存进本地数据库（以后少打网）。  
2. **读出来**变成表格，给算因子用。  
3. 真正给阶段 2 用的，是再导出的 **parquet 文件**（一种存表格的文件格式，比 csv 更省、读得快）。

## 从 Tushare 拉了哪些东西？

可以想成几张购物小票：

| 小票 | 大概内容 |
|------|----------|
| 成分股名单 | 研究开始那天附近，沪深300里有哪些股票 |
| 股票名片 | 名字、上市日、行业（尽量用申万一级行业名） |
| 日线行情 | 开、高、低、收、成交量、成交额 |
| 每日资料 | 换手率、市盈率、市净率、总市值、流通市值等 |
| 复权因子 | 用来把分红送股前后的价格「接到同一尺子上」 |
| ST 记录 | 哪些时段这只股票被标成风险股 |

**复权（白话）**：股票分红送股后，名义价格会跳一下。复权就是把历史价格按同一标准接起来，避免「假大跌」。

## 内存里读出来时的形状

`load_data()` 返回一个字典，里面几张表。多数表的行标签是两层：`(date, code)`，日期仍是 `"20190101"` 这种字符串。

## prices.parquet（导出后）

逻辑钥匙：`(trade_date, ts_code)`，文件里是普通列，没有花哨索引。

| 列 | 意思 |
|----|------|
| `trade_date` | 交易日，如 `20190102` |
| `ts_code` | 股票代码，如 `000001.SZ` |
| `open/high/low/close` | 开高低收（库里的原始价） |
| `volume` | 成交量（从库里的 `vol` 改名而来） |
| `adj_factor` | 复权因子 |
| `tradable` | 这一天能不能当真去买（True/False） |

日期格式：**八位字符串**，不是 `2019-01-02`。

注意：表里存的是**未复权**原始价；算因子时，代码里会再按规则做前复权。

## meta.parquet（导出后）

同一把钥匙 `(trade_date, ts_code)`，加上：

- `industry`：行业名字  
- 一串每日资料：换手、估值、股本、市值等（大约 15 个字段）

阶段 2 做 IC/回测时，主要读 `prices` 和 `factors_clean`；`meta` 更多是资料备份和清洗时用过的信息来源。

## 怎么自己核对（以后有数据时）

- 打印列名，应能看到上面那些列。  
- `trade_date` 应全是 8 位数字字符。  
- 同一天股票数量大约在一两百到三百（成分会变、也会有缺失）。  
- `tradable` 里 False 不应是 0% 或 100%（全可买或全不可买都不像真的）。
