# 第 0 课：这个项目在干什么？

> 对照仓库：`Parsnip77/`  
> 目标：先看懂流程，还不写代码。

## 一句话

用历史行情算出一些「打分规则」（叫**因子**），看这些分数能不能帮你挑出更可能涨的股票，再用过去数据假装交易，看赚不赚。

- **因子**：对每只股票、每个交易日算出的一个分数。分数高/低表示按这条规则更看好/看空。
- **回测**：用历史数据模拟「按规则买卖会怎样」，不是真金白银下单。

## 三个大阶段

### 阶段 1：准备数据 + 算因子 + 洗干净

入口脚本：`data_preparation_main.py`

| 做什么 | 吃什么（输入） | 吐什么（输出） |
|--------|----------------|----------------|
| 下载行情等 | 网上数据接口 Tushare | 本地数据库 `stock_data.db` |
| 算原始因子 | 价格、成交量等 | `factors_raw.parquet` |
| 清洗因子 | 原始因子 + 市值、行业 | `factors_clean.parquet` |
| 顺带导出行情/资料 | 数据库里的表 | `prices.parquet`、`meta.parquet` |

四张表用同一把「钥匙」对齐：`(交易日 trade_date, 股票代码 ts_code)`。

### 阶段 2：检查因子有没有用 + 假交易

入口脚本：`analyze_main.py`

| 做什么 | 吃什么 | 吐什么 |
|--------|--------|--------|
| 算「明天涨多少」当答案 | `prices.parquet` | 一列未来收益 |
| 算 IC | 清洗后的因子 + 未来收益 | 每天一个相关程度数字 |
| 分层回测 | 同上 | 把股票按分数切成 5 组，看各组赚多少 |
| （可选）把几个好因子合成一个 | 筛出来的因子 | 合成因子的 IC 和回测图 |
| 写报告 | 上面结果 | `result.txt` 和 `plots/` 里的图 |

**IC（信息系数）**：今天分数高的股票，是不是更容易在之后涨。数字越稳定地偏离 0，这条规则越像有用。细节见第 5 课。

注意：README 写了「扣手续费」，但阶段 2 现在的代码**没有扣**。以后复写时若要扣，要单独加。

### 阶段 3：用机器学习再合成（精简版可先不做）

入口：`ml_analyze_main.py`。用很多因子当输入，训练一个模型打总分。先把阶段 1、2 搞懂再说。

## 流程总览（对着讲）

1. 选定一批股票（沪深300在研究开始时的成分，尽量别用「今天的名单」偷看未来）。  
2. 下载每天的开高低收、成交量、市值、行业、复权、ST 等。  
3. 标出哪些天这只股票其实买不了（停牌、涨跌停、ST 等）。  
4. 用价格和成交量算出多个因子分数。  
5. 把极端离谱的分数压一压，并尽量去掉「只是因为公司大/属于某行业」带来的偏斜。  
6. 存成 parquet，方便后面反复读。  
7. 用收盘价算「持有几天后赚了百分之几」。  
8. 看因子分数和未来收益是否同向/反向相关（IC）。  
9. 按分数分 5 组假持有，看高分组是不是比低分组赚得多。  
10. （可选）再把多个因子合成；更后面才上机器学习。
